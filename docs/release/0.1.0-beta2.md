## What changes in HCG Repo when it is imported (for HCG Repo's maintainer)

1. `bin/hcgrepo import-request` on the handoff's `import-request.toml`, with `--dry-run` first. It downloads the
   artifact and refuses any bytes whose SHA-256 differs from the one above.
2. `packages/com.hakmicapitalgroup.hcgsentinel/package.toml`: the handoff's version, with `[access]
   exception_versions = ["0.1.0~beta1", "0.1.0~beta2"]` and the owner's approval text for beta2 added to
   `exception`. The beta1 approval stays as it is.
3. `CHANGELOG.md`: the handoff's 0.1.0~beta2 entry.
4. `config/products.toml`, product `hcg-sentinel`: `name = "HCG Sentinel Unleashed"`, and update the stale entry
   (`package_ids = []`, `kind = "App — no jailbreak package"`, `detail = "…nothing to install…"`) to list
   `com.hakmicapitalgroup.hcgsentinel` as a rootless app in Candidate. The `store_slug` stays `hcg-sentinel`.
5. Listing text (`notes`, `install`, `known_issues`): see below. Remove "Not yet device-tested" only when a device
   result is recorded.
6. Future HCG Store metadata: product name "HCG Sentinel Unleashed", same slug, Home Screen name Sentinel.

beta1 stays in the pool, unchanged and still installable, as the rollback target.

### Proposed listing text

- **Summary:** Toolkit for authorised testing of your own devices, networks and services: Bluetooth LE discovery,
  Wi-Fi and local network diagnostics, ping.
- **Install:** 1. Refresh HCG Repo Candidate and install or upgrade **HCG Sentinel Unleashed**. 2. The package
  registers the app with `uicache`; the icon is named **Sentinel**. 3. If the icon does not appear, run
  `uicache -p /var/jb/Applications/HCGSentinelModern.app`; respring only if that does not help. Sentinel never
  resprings by itself.
- **Known issues:** not yet device-tested; nearby Wi-Fi networks and the network name are not available to this
  build; HCG sign-in is not included; iOS 15.0 or later only; another build with bundle ID `com.hcg.sentinel` (Xcode,
  IPA) must not be installed at the same time.
- **Rollback:** install 0.1.0~beta1 from the package's version list, or `sudo dpkg -i` the beta1 .deb; then
  reinstall beta2 when ready. Removing the package removes the app; its data container stays.

## Validation already done (CI, no device)

See [VALIDATION.md](../VALIDATION.md#beta2-010beta2-21-november-2026). In short: real iOS arm64 Release build
(minimum iOS 15.0); rootless layout under `/var/jb` only; dependencies `firmware (>= 15.0), uikittools`, as in beta1;
ldid pseudo-signature with **no entitlements**, as in beta1; `postinst`/`postrm` byte-identical to beta1; Maker's
validator for iOS 16.5 and 17.4; HCG Repo inspector; HCG Repo importer dry run (bytes valid, import blocked only by the
missing approval); dpkg sandbox upgrade beta1 → beta2, rollback to beta1, removal and purge.

**Not done:** any test on a physical iPhone.
